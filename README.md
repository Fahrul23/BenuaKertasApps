# Benua Kertas Apps

Sistem manajemen percetakan berbasis web untuk **Benua Kertas**.

## Tech Stack

### Client
- React 18 + Vite
- React Router v6
- Redux Toolkit
- Axios
- Tailwind CSS
- shadcn/ui
- React Hook Form + Zod

### Server *(coming soon)*
- Node.js + Express
- ...

## Struktur Monorepo

```
benua-kertas-apps/
├── client/   ← React frontend
└── server/   ← API backend (coming soon)
```

## Menjalankan Client

```bash
cd client
npm install
npm run dev
```

> Salin `.env.example` ke `.env` dan sesuaikan variabel lingkungan.
